The systematic approach to identifying challenges and crafting logical, step-by-step solutions for computational agents.

01. The Definition

What is a Problem?

In computer science and logical reasoning, a problem is defined as any situation that presents a challenge, an obstacle, or a question that does not have an immediate or obvious answer. It is the gap between the current state and the desired state.

To solve a problem effectively, we must understand its three core components:

1. Input State

The data, information, or resources currently available to us.

2. Output State

The goal or final result we want to achieve.

3. Constraints

The rules, limitations, or boundaries we must work within.

02. Problem Solving Cycle

1

Identify the Problem

This involves recognizing and defining the problem clearly. You must be able to state what is wrong or what needs to be accomplished. If the problem is not correctly identified, the solution will likely be irrelevant.

2

Analyze the Problem

Once identified, you must analyze the problem to understand its depth. This includes identifying the required inputs, the expected outputs, and the specific constraints or limitations (like time, cost, or memory).

3

Solution Design

In this phase, you plan the actual path to the goal. You might use tools like flowcharts or pseudocode. The focus is on the logic: "What steps must be taken to convert the input into the output?"

4

Testing & Evaluation

After creating a solution, it must be verified. You test it with various inputs (including extreme or incorrect ones) to ensure the output is consistent and accurate. If errors are found, you go back to previous steps to refine the logic.

03. The Algorithm

What is an Algorithm?

An Algorithm is a finite set of clear, step-by-step instructions designed to perform a specific task or solve a particular problem. In the digital world, algorithms are the brains behind software, telling the computer exactly what to do at every microsecond.

"If a problem is the destination, the algorithm is the GPS navigation that tells you every turn to take to get there safely."

04. Quality Traits

Characteristics of a Good Algorithm

Clear & Unambiguous

Each step must be precisely defined. There should be no room for multiple interpretations or confusion for the executor.

Finite (Finiteness)

An algorithm must eventually stop. It must terminate after a specific number of steps and should not result in an infinite loop.

Step-by-Step

The instructions must be in a distinct, logical sequence. The order is critical because moving a step out of place changes the final outcome.
