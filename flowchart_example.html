1. Largest of Three Numbers

Problem Explanation

This problem helps students learn comparison and decision-making. The system takes three numbers as input and determines which number is the greatest.

Animated Flowchart

START
⬇
Input A, B, C
⬇
Compare Numbers
⬇
Find Largest Number
⬇
Display Largest Number
⬇
STOP

Pseudocode

START
INPUT A, B, C

IF A > B AND A > C THEN
    PRINT A
ELSE IF B > C THEN
    PRINT B
ELSE
    PRINT C
END IF

STOP

2. Even or Odd Number

Problem Explanation

This problem teaches modulus operator and logical conditions. If a number is divisible by 2, it is even; otherwise, it is odd.

Animated Flowchart

START
⬇
Input Number N
⬇
Check N % 2
⬇
Display Even or Odd
⬇
STOP

Pseudocode

START
INPUT N

IF N % 2 == 0 THEN
    PRINT "Even"
ELSE
    PRINT "Odd"
END IF

STOP

3. ATM Withdrawal System

Problem Explanation

This problem teaches students about conditions and validation. The ATM allows withdrawal only if sufficient balance is available.

Animated Flowchart

START
⬇
Input Balance
⬇
Input Withdrawal Amount
⬇
Check Balance
⬇
Display Result
⬇
STOP

Pseudocode

START
INPUT Balance
INPUT Amount

IF Amount <= Balance THEN
    Balance = Balance - Amount
    PRINT Balance
ELSE
    PRINT "Insufficient Balance"
END IF

STOP

4. Student Grade System

Problem Explanation

This activity helps students understand nested conditions and decision-making. The program checks marks and assigns grades according to score range.

Animated Flowchart

START
⬇
Input Marks
⬇
Check Grade Conditions
⬇
Assign Grade
⬇
Display Grade
⬇
STOP

Pseudocode

START
INPUT Marks

IF Marks >= 90 THEN
    PRINT "Grade A"
ELSE IF Marks >= 75 THEN
    PRINT "Grade B"
ELSE IF Marks >= 50 THEN
    PRINT "Grade C"
ELSE
    PRINT "Fail"
END IF

STOP
